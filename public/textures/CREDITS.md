All JPEG maps in this directory are by Solar System Scope (INOVE), from https://www.solarsystemscope.com/textures/, distributed under Creative Commons Attribution 4.0 International: https://creativecommons.org/licenses/by/4.0/.

Source files: `2k_mercury.jpg`, `2k_venus_atmosphere.jpg`, `2k_earth_daymap.jpg`, `2k_earth_clouds.jpg`, `2k_mars.jpg`, `2k_jupiter.jpg`, `2k_saturn.jpg`, `2k_uranus.jpg`, `2k_neptune.jpg`, `2k_sun.jpg`, `2k_moon.jpg` from that page's `/textures/download/` links. Retrieved 2026-11-18. Adaptation: resized to 1024px and recompressed for web performance, with file names shortened.

The source maps incorporate NASA imagery and artistic gap filling. Maps, lighting and atmospheric effects are illustrative; they are not live imagery. The Moon map is used only for Earth's Moon. Other moons retain their catalogue colour.
